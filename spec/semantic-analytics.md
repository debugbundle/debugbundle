## Acceptance

### AC-ANL-SEMANTIC-WIRE

- A canonical sessionless server fact and consented browser/mobile events round-trip losslessly.
- Missing/malformed/unknown fields, false client authority, mismatched producer/runtime, fabricated server sessions, invalid context combinations and money overflow are rejected.
- Strict/standard/custom identity constraints hold before ingestion additionally verifies trusted namespace/catalog/credential policy.
- Durable operation identity is required for server business facts and rejected on browser/mobile or server product events; the `sha256:` shape alone does not prove that the application used a high-entropy or secret-keyed source.
- Every measurement/money value survives JSON across languages without floating-point coercion; total event UTF-8 bytes are bounded.
- Unchanged V1 and debug schemas reject V2 rather than silently coercing it; existing V1 fixtures still pass.

### AC-ANL-SEMANTIC-SAFETY

- Disabled/consent-blocked/full capture rejects before application traversal. Throwing/proxy/cyclic/deep/wide input cannot escape or grow pending state without bound.
- Mandatory privacy corpus is absent from the first memory snapshot, deferred work, disk, bridge, relay and HTTP bytes; safe diagnostic fields survive.
- Existing debug callback timing/replacement/drop/fallback and suppression remain compatible. Finalized analytics retries do not re-run callbacks, timestamps, identity or sampling.
- An analytics burst/stalled sender cannot consume reserved debug capacity; combined queued/in-flight/retired ownership and finite flush deadlines remain enforced.

### AC-ANL-SEMANTIC-CONSENT

- Populated ordinary/threshold/retry/lifecycle/native queues are purged or fenced at withdrawal before new dispatch; stale config/crypto/hook/transport completions cannot restore them.
- Re-grant and account switch use fresh authorized context; debug events/session remain independently functional.
- Revoke between keepalive body preparation and the actual fetch call prevents dispatch. Already-transmitted requests/beacons retain honest ownership/recall limitations.
- Remote tightening, repeated init, multi-instance storage and native restart pass equivalent tests; no injected consent UI.

### AC-ANL-SEMANTIC-AUTHORIZATION

- Same-org space membership and every-source access are required on initial reads, queued jobs, cache hits, export and artifact retrieval.
- Public tokens/relays cannot spoof a server writer or known-user association; writer rotation/revocation and old-server rejection fail closed.
- Financial facts require a trusted billing-source namespace independent of subject/space identity; an unbound writer cannot stage, charge quota or receive a financial receipt.
- Handoff expiry/replay/origin/account-switch and captured prompt-injection fixtures do not disclose identity or execute instructions.
- Catalog preview is read-only; revision conflicts/idempotency preserve exactly one authorized change.
- Every active space report charges one saved-report slot to each linked source, including when a project plan or legacy funnel changes after space activation; capacity changes cannot leave an unauthorized active report.

### AC-ANL-SEMANTIC-METRICS

- Hand-calculated fixtures include A-only/B-only different subjects, B-before-A, repeated entry, equal-time ambiguity, outside-window steps, late arrivals, team participation and immature cohorts.
- Exact union counts span hour/day/project boundaries. Retention censoring and source-access/exclusion filters preserve matched numerators/denominators.
- Attribute each conversion once per model and report linkage gaps. Payments/refunds and subscription state reconcile independently under duplicates/out-of-order updates, annual billing, trials, proration and currency exponents.
- Missing/expired/sampled/lost evidence produces explicit quality states, not zero or unqualified exact totals. Identical normalized artifact inputs remain byte-identical.

### AC-ANL-SEMANTIC-DURABILITY

- Concurrent retries/lost ACKs do not duplicate ingress quota, operations, rollups, bundles or publication; ACK indices refer to original mixed-batch positions.
- V2 charges the active server-derived organization billing period at the effective paid tier-and-capacity allowance; a caller-supplied period, stale paid period or mid-write period/capacity change cannot produce an ACK in the wrong bucket.
- The negotiated V2 capability exposes `max_event_age_seconds` separately from report `correction_seconds`; SDKs intersect it with their own shorter local queue lifetimes. The project-only intake derives an inclusive seven-day event-age boundary from receipt time and rejects a caller-supplied earlier horizon; the internal persistence handoff captures that time from its own trusted server clock; a future route must not substitute a caller value. Report correction and finalized revision behavior remain separate gates.
- An unchanged old retry can return only its original unexpired receipt after current authority and protected-content checks. A different event, changed content, revoked grant or removed receipt cannot use the retry exception to create a new accepted fact.
- Persistence/enqueue/worker/artifact crash points preserve recoverable ownership. New processors do not bypass the shared dequeue/journal contract or correlation lock order.
- Outbox cleanup follows durable acceptance only. Terminal failures are observable without customer payload diagnostics; retries and receipt horizons are finite.
- Minimal server business operation keys continue to deduplicate through project lifetime while bounded raw objects and transport receipts expire separately; deletion removes the keys and erasure/storage-cost behavior is qualified.
- Cleanup/unlink/delete fences delayed work; migrations from populated predecessors precede startup/readiness and rollback preserves installed debug data.
- The server delivery adapter derives its hash from a validated `dbundle_anl_` bearer, binds the writer project, rejects browser Origin and over-limit bodies, and returns only indexed durable receipts or bounded errors. Its hosted candidate shares the per-credential ingestion limiter at the current tier rate, returns indexed retryable `429` results on denial and fails closed when rate policy or limiter is unavailable. This does not bound aggregate writer/project bursts or qualify cleanup throughput. The mixed client adapter derives its hash from an authenticated direct project bearer, uses the same policy/receipt service and shared rate limiter, and maps durable acceptance or terminal reasons to original V1 batch indexes. The composed runtime remains disabled until full projections, loss-quality, identity/relay and cleanup-capacity gates pass.

### AC-ANL-SEMANTIC-RELEASE

- The first usable JavaScript release presents one current Analytics setup and one Analytics UI. Internal event-schema negotiation is not a customer-facing product selector. A reviewed migration guide covers installed browser methods and the site/app dogfood cutover; mixed installed versions neither duplicate a fact nor merge unverified legacy aggregates into new report denominators. Historic V1 reports/artifacts remain readable for their stated retention, and any later removal of old collection follows the explicit deprecation path.
- Contract, privacy, safety and transport corpora pass in every SDK activated by this candidate plus clean installed artifacts at its supported runtime/framework versions. Deferred SDKs retain V1 compatibility and require their own V2 activation proof later.
- Old/new JavaScript browser/Node SDK, API, relay and config matrices pass; unsupported V2 leaves existing debugging operational. Later native-bridge matrices apply before a native V2 activation.
- Existing PHP/WordPress request-end behavior and native bridge behavior stay compatible. Their V2 writers, both RN bridges and the assembled WordPress ZIP require their own exact-dependency gate before later activation.
- Existing API/CLI/MCP/web answers remain compatible; new operations have domain-service parity and matching docs. Hosted OpenAI V1 remains frozen.
- Quantitative debug performance/retention bounds and exact dependency-ordered registry verification pass before release; production/browser/device claims require separate evidence.
