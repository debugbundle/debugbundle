# DebugBundle creator starter kit

Use the DebugBundle artwork as supplied. Use the sample checkout incident when
recording or sharing examples so your audience can follow along without access
to a private workspace.

## Three things to show

1. Open the sample checkout incident. Explain what the timeline and redacted
   evidence tell you, then point out what you would inspect next.
2. Give the sample bundle to your coding agent. Ask it to summarise the incident,
   identify what evidence supports its explanation, and suggest a next check.
   Review the answer before showing it.
3. Set up DebugBundle in a small demo project. Capture a test error and open the
   resulting bundle using the local-first workflow.
